# DryFarming

A Minecraft mod that prevents farmland from drying out, even when there is no water nearby.

## Requirements
- Minecraft 26.1.2
- Fabric Loader 0.19.3 or later
- Fabric API

## Installation
1. Install Fabric Loader.
2. Place Fabric API in your `mods` folder.
3. Place this mod JAR file in your `mods` folder.

## Features
- Farmland never dries out due to the absence of nearby water.
- Jumping on farmland still turns it back into dirt, as in vanilla.
